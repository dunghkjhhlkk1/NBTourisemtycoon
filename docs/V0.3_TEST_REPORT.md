# Kiểm thử V0.3

- ASP.NET Core build thành công. PostgreSQL áp dụng migration và tạo dữ liệu mẫu.
- Kiểm thử API trên cơ sở dữ liệu riêng đã qua. Hai yêu cầu thuê đồng thời chỉ một yêu cầu thành công. API từ chối thuê khu bảo tồn, tự tạo tiền, chỉnh cơ sở chưa thuê, xây ngoài lô hoặc sai loại. Retry xây không tạo bản ghi thứ hai. Nhà hàng có sẵn và cơ sở xây mới đều tạo doanh thu khi không có Godot kết nối.
- Kiểm thử Godot V0.2 smoke và tourism đều PASS trong chế độ offline.
- Địa chỉ demo dùng HTTP loopback hiện có. Chứng chỉ HTTPS và tài khoản nhiều người chơi nằm ngoài thiết lập demo hiện tại.
- Mô hình thị trường là phép tính theo kỳ. Hoạt ảnh khách Godot có thời gian riêng. Phần hình ảnh tập trung vào ranh giới lô và bảng quản lý, dùng sprite và địa hình hiện có.

- Đã mở Web build trên trình duyệt và xác nhận bản đồ, vốn đồng bộ, bảng điều kiện thuê nhà hàng. Luồng ghi dữ liệu được kiểm tra bằng API trên cơ sở dữ liệu thử.
- Bản chỉnh giao diện thêm thanh HUD xanh đậm, bảng tài sản bên phải, biển tên công trình, sân lát đá và bến gỗ. Smoke và tourism chạy lại đều PASS.
- Tối ưu tìm đường và giảm cập nhật giao diện. Benchmark Godot headless 6.200 tick: 1323 ms trước và 1183 ms sau, cùng 456 bút toán. Smoke và Tourism đều PASS. Số đo headless không phải FPS trình duyệt.
