# Kiến trúc V0.3

Game giữ nguyên đường dẫn dự án Godot. Mã ASP.NET Core ở backend, phân theo Domain, Application và Infrastructure. PostgreSQL quản lý hợp đồng, cơ sở, sổ thu chi và kết quả thị trường. Kestrel phục vụ cả Web export và API từ cùng origin. Client web đọc origin hiện hành. Bản chạy trong editor mặc định kết nối localhost:8766.

Server tính phân bổ nhu cầu theo ngành, giá, khoảng cách, cấp và công suất mỗi 15 giây. NPC cạnh tranh trong cùng ngành. Vòng khách, hàng đợi và chuyến thuyền Godot chạy độc lập để hiển thị. Thời gian và doanh thu thị trường lấy theo đồng hồ server. Phiên chạy hiện tại có một doanh nghiệp người chơi và xác thực demo chỉ cho loopback.

Khởi động API từ thư mục backend với biến ConnectionStrings__Tourism trỏ vào cơ sở dữ liệu PostgreSQL trống dành cho game. Migration và seed chạy khi khởi động. Chạy `dotnet run --urls http://localhost:8766`. Cấu hình chứng chỉ Kestrel nếu dùng HTTPS, rồi dùng một URL duy nhất cho game và API. Tùy chọn Godot `-- --offline-v02` mở sandbox V0.2.
